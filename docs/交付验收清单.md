# 交付验收清单

## 构建检查

推荐直接运行统一检查：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify-all.ps1
```

脚本会执行 API 的 lint、单元测试、构建，后台的 lint、单元测试、类型检查、构建，以及客户 App 的锁定依赖安装、分析和测试；后台入口包含超级管理员、管理员、财务、业务员和专用运营员五个端口。

如果只想跑代码检查、单元测试和构建，不跑会写入测试数据的业务冒烟：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify-all.ps1 -SkipVerification
```

也可以分别执行：

```powershell
cd apps/api
npm run build

cd ../admin
npm run build

cd ../..
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-backends.ps1 -SkipBuild
```

客户 App：

```powershell
cd apps/client
flutter analyze
flutter build web --dart-define=API_BASE_URL=http://localhost:3000
```

Android 包需要本机先配置 `JAVA_HOME` 和 release keystore。

## 核心业务冒烟

项目根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\verification-test.ps1
```

先设置 `BUSINESS_INITIAL_PASSWORD`、`SUPPORT_INITIAL_PASSWORD`、`FINANCE_INITIAL_PASSWORD` 和 `ADMIN_INITIAL_PASSWORD`，并为 `BUSINESS001` 准备一个未使用的邀请码。没有邀请码时脚本会报错退出，不会自动生成。只对隔离测试环境执行；Docker 环境需要加 `-BaseUrl http://localhost:3100`。

脚本会验证：

- 印度手机号 + 密码 + 邀请码注册
- KYC 上传 PAN/Aadhaar
- 业务员审核 KYC
- 客户联系在线客服咨询入金
- 客服标签
- 财务手动上分
- 客户提交提现申请
- 提现订单号生成
- 业务员可见自己客户提现记录
- 财务审核提现
- 客户通过测试 API 下单（不代表外部交易所成交已验证）
- 管理员可见订单
- 财务可见成交
- 业务员可见自己客户订单

## 交易权限验收

客户买入股票后确认：

- 客户订单状态为 `FILLED`
- 管理员可在订单/成交查询中看到
- 财务可在订单/成交查询中看到
- 业务员只能在自己的客户订单/成交记录中看到
- 客服不能访问业务员交易接口（需单独执行越权测试，当前冒烟脚本未覆盖）

## Android 安装与业务 E2E 的区别

`scripts/build-android-e2e.ps1` 只检查本机 API、建立 USB 端口映射并构建安装、启动 App。它不会自动点击页面或验证资金流程，不能作为完整 Android E2E 通过的证据。完整发布门槛见 `docs/上线准备与验收.md`。

## 生产上线前

完整清单见 `docs/生产部署说明.md`。至少确认：

- `NODE_ENV=production` 与全部必填密钥（`JWT_SECRET`、`TWO_FACTOR_ENCRYPTION_KEY`、`OTC_KEY_ENCRYPTION_SECRET`、`OBJECT_SIGNING_SECRET`、`ADMIN_FIXED_INVITE_CODE`、各 `*_INITIAL_PASSWORD`）
- API `CORS_ORIGINS` 含五个后台域名（及可选客户 Web）
- `VIRUS_SCAN_URL`（HTTPS）与持久 `PRIVATE_OBJECT_ROOT`
- 五个后台分别用正确的 `NEXT_PUBLIC_BACKEND_ROLE` **构建**后部署
- 客户 App `API_BASE_URL`
- 数据库自动备份（`scripts/backup-postgres.sh` + cron）
- 修改默认后台员工密码
- 配置 Android `key.properties` 和 release keystore
