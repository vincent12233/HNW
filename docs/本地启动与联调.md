# 本地开发（无 Docker）

正式环境请按 `docs/生产部署说明.md` 在服务器上部署。本文仅说明本机用 Node + PostgreSQL 直接跑服务（不使用 Docker / compose）。

## 1. 准备 PostgreSQL 和 Redis

本机安装 PostgreSQL 17.x，创建数据库与用户（示例）：

```sql
CREATE USER hnw_user WITH PASSWORD '请换成强密码';
CREATE DATABASE hnw_trading OWNER hnw_user;
CREATE DATABASE hnw_trading_shadow OWNER hnw_user;
```

Redis 为可选的本机共享限流存储；未配置时开发环境使用进程内计数。需要模拟多实例时启动 Redis，并设置 `RATE_LIMIT_REDIS_URL=redis://127.0.0.1:6379`。

## 2. 配置 API

```powershell
cd apps/api
Copy-Item .env.example .env
```

将 `.env` 中的 `DATABASE_URL` / `SHADOW_DATABASE_URL`、JWT 与各角色初始密码改为本地值。

```powershell
npm ci
npm run db:generate
npm run db:migrate
npm run seed
npm run start:dev
```

默认地址：`http://localhost:3000`  
健康检查：`http://localhost:3000/health`

## 3. 启动管理后台

```powershell
cd apps/admin
Copy-Item .env.example .env.local
```

设置 `NEXT_PUBLIC_API_URL=http://localhost:3000`，按需设置 `NEXT_PUBLIC_BACKEND_ROLE`，然后：

```powershell
npm ci
npm run dev
```

或一次拉起五个角色端口：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-backends.ps1
```

| 角色 | 地址 |
| --- | --- |
| 超级管理员 | http://localhost:3002/login |
| 管理员 | http://localhost:3004/login |
| 财务 | http://localhost:3005/login |
| 业务员 | http://localhost:3006/login |
| 专用运营员 | http://localhost:3007/login |

## 4. 客户 App

```powershell
cd apps/client
flutter pub get
flutter run --dart-define=API_BASE_URL=http://localhost:3000
```

## 5. 种子账号

| 超级管理员 | ADMIN001 | `ADMIN_INITIAL_PASSWORD` |
| 管理员 | MANAGER001 | `MANAGER_INITIAL_PASSWORD` |
| 财务 | FINANCE001 | `FINANCE_INITIAL_PASSWORD` |
| 业务员 | BUSINESS001 | `BUSINESS_INITIAL_PASSWORD` |
| 专用运营员 | SUPPORT001 | `SUPPORT_INITIAL_PASSWORD` |

密码来自 API 环境变量，项目不提供固定默认口令。

## 6. 数据库备份 / 恢复（本机或服务器）

使用系统自带的 `pg_dump` / `pg_restore`（需在 PATH 中）：

```powershell
$env:DATABASE_URL = "postgresql://hnw_user:密码@127.0.0.1:5432/hnw_trading"
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\backup-postgres.ps1 -OutputPath .\backups\hnw.dump
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\restore-postgres.ps1 -InputPath .\backups\hnw.dump
```
