# 项目交付总览

本文档用于保存当前 HNW Trading Platform 的完成范围、启动方式、账号信息、验收方式和上线准备事项。

## 当前完成状态

项目开发和本地验收已基本完成。当前统一验证脚本覆盖 API、四个分离的运营后台和客户 App 分析检查，以及核心业务冒烟流程。

尚未完成的是外部上线环境相关工作，包括正式服务器、正式域名、HTTPS、正式数据库备份、Android release 签名和应用商店资料。

## 核心业务规则

- 客户 App 统一英文。
- 后台系统统一中文。
- 客户注册只需要印度手机号、登录密码、邀请码。
- 客户注册不使用邮箱，不使用短信验证码。
- 后台员工不使用邮箱体系，只使用员工编号和密码登录。
- 客户注册成功后，系统自动生成内部客户编号，该编号客户不可见。
- 注册完成后进入 KYC 上传页面。
- KYC 支持 Aadhaar 或 PAN 文件上传。
- KYC 由客户所属业务员在后台审核。
- 客户入金不在 App 内提交申请。
- 客户点击 Deposit 或 Contact Support 后进入在线客服。
- 客服提供充值方式，财务确认后在后台手动上分。
- 客户提现在 App 内提交申请。
- 提现申请生成订单号，客户提现记录和后台提现记录都能查看。
- Trading 页原 Funds 改为 History，用于展示卖出后的历史记录。
- 手机端底部导航保持 Portfolio，不改成 Funds。

## 后台角色权限

| 角色 | 可见范围 | 可操作内容 |
| --- | --- | --- |
| 管理员 | 所有客户和后台模块 | 用户管理、客户管理、行情维护、订单成交查看、后台模块管理 |
| 财务 | 所有客户、账户、入金、提现、订单、成交 | 单人上下分与上分订单、提现审核、资金流水查看（无需双人复核） |
| 业务员 | 只能查看自己的客户 | 邀请码、客户、KYC、入金记录、提现记录、订单、成交记录查看 |

业务员不能审核提现，不能提现上分。客服会话由 SaleSmartly 工作台处理，客户 App 不显示内部客户标签。

## 本地启动顺序

先打开 Docker Desktop，然后启动数据库：

```powershell
docker compose up -d postgres
```

启动 API：

```powershell
cd apps/api
Copy-Item .env.example .env
npm run db:migrate
npm run db:generate
npm run seed
npm run start:dev
```

启动四个运营后台：

```powershell
cd ..\..
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-backends.ps1
```

启动客户 App：

```powershell
cd apps/client
flutter pub get
flutter run --dart-define=API_BASE_URL=http://localhost:3000
```

默认地址：

| 服务 | 地址 |
| --- | --- |
| API | `http://localhost:3000` |
| 超级管理员后台 | `http://localhost:3002/login` |
| 管理员后台 | `http://localhost:3004/login` |
| 财务后台 | `http://localhost:3005/login` |
| 业务员后台 | `http://localhost:3006/login` |
| 专用运营员后台 | `http://localhost:3007/login` |

## 一键验证

完整验证：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify-all.ps1
```

快速验证，不跑业务冒烟：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify-all.ps1 -SkipVerification
```

业务冒烟脚本会验证：

- 印度手机号注册
- 邀请码使用
- PAN/Aadhaar KYC 上传
- 业务员审核 KYC
- 客户联系在线客服
- 客服内部标签
- 财务手动上分
- 客户真实下单
- 管理员可见订单
- 财务可见成交
- 业务员只能看到自己客户订单
- 客户提交提现
- 提现订单号生成
- 业务员可见自己客户提现记录
- 财务审核提现

## 生产上线准备

上线前需要准备：

- API 正式域名，例如 `https://api.example.com`
- 管理后台正式域名，例如 `https://admin.example.com`
- PostgreSQL 正式数据库
- 数据库自动备份
- HTTPS 证书
- API `JWT_SECRET`
- API `CORS_ORIGINS`
- 后台 `NEXT_PUBLIC_API_URL`
- 客户 App `API_BASE_URL`
- Android release keystore
- 应用图标、包名、隐私政策和应用商店资料

## Android 打包

正式 APK：

```powershell
cd apps/client
flutter build apk --release --dart-define=API_BASE_URL=https://你的API域名
```

正式 AAB：

```powershell
flutter build appbundle --release --dart-define=API_BASE_URL=https://你的API域名
```

正式发布前必须配置 `apps/client/android/key.properties` 和 release keystore。

## 重要安全提醒

- 不要提交 `.env`、`.env.local`、`key.properties`、keystore 文件。
- 不要把真实数据库密码写入文档。
- 生产环境必须修改默认后台账号密码。
- 数据库建议只允许服务器内网访问。
- 财务上分、提现审核、客户资料、KYC 文件都应定期备份。
- 上线前应再跑一次完整验证脚本。
