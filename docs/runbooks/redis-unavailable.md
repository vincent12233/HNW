# Redis 不可用处置手册

## 影响与触发

生产就绪探针失败、限流存储断开或分布式任务租约不可用时触发。生产环境按失败关闭处理，避免绕过限流和重复调度。

## 检查顺序

1. 检查 Redis 服务、TLS/凭据、网络、内存、连接数和故障转移状态，不输出完整连接串。
2. 核对 API 就绪状态、限流队列、撮合与 DAY 到期租约持有者。
3. 检查最近配置/发布变更和多个实例是否同时执行单实例任务。
4. Redis 恢复后验证租约所有者令牌和 Lua 安全释放路径。

## 安全缓解与回滚

- 从负载均衡移除未就绪实例；必要时暂停新写入，保留安全只读能力。
- 恢复 Redis 或回滚错误配置；逐步恢复流量并观察限流、租约和队列指标。
- 恢复后运行订单/资金对账，确认没有重复工作或状态差异。

## 升级与禁止事项

通知平台和值班负责人；如果出现重复撮合、重复到期或限流失效，升级为重大事件。

禁止在生产切换到进程内限流、关闭认证/限流、无所有者校验地删除锁或用 `FLUSHALL` 清理状态。
