# Reference Screen Evidence

This directory records approved visual evidence. Do not copy branding, assets, or proprietary layouts from other apps. Groww, Zerodha Kite, Upstox, and Angel One are interaction references only: clear hierarchy, compact market data, explicit freshness, safe confirmations, and honest failure states.

For each accepted change record the route/screen, commit, viewport, locale, text scale, state, before/after artifact location, reviewer, and confirmation that protected business behavior is unchanged. Do not store customer data, tokens, internal endpoints, or production screenshots containing personal information.
