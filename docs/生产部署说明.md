# 生产部署说明

这份说明用于把当前项目部署到正式服务器。正式环境至少需要一台后端服务器、一个 PostgreSQL 数据库、三个可访问域名，以及客户 App 的正式 API 地址。

## 推荐域名

| 用途 | 示例 |
| --- | --- |
| API 后端 | `https://api.example.com` |
| 管理后台 | `https://admin.example.com` |
| 独立客服端 | `https://support.example.com` |
| 客户 Web App，可选 | `https://app.example.com` |

如果只发布 Android App，客户 Web App 域名可以不配置。

## 服务器环境

推荐准备：

- Node.js 20 或更高版本
- npm
- PostgreSQL 15 或更高版本
- Flutter SDK，用于客户 App 打包
- Java JDK，用于 Android APK/AAB 打包
- Nginx 或同类反向代理
- HTTPS 证书

## API 后端

进入 API 目录：

```powershell
cd apps/api
Copy-Item .env.example .env
```

修改 `.env`：

```env
DATABASE_URL="postgresql://正式数据库用户:正式数据库密码@数据库地址:5432/正式数据库名?schema=public"
SHADOW_DATABASE_URL="postgresql://正式数据库用户:正式数据库密码@数据库地址:5432/正式影子数据库名?schema=public"
JWT_SECRET="换成高强度随机密钥"
CORS_ORIGINS="https://admin.example.com,https://support.example.com,https://app.example.com"
PORT=3000
MATCHING_MAX_FILL_QUANTITY=1000
UPSTOX_ACCESS_TOKEN=
```

安装依赖、迁移数据库、构建并启动：

```powershell
npm install
npm run db:migrate
npm run db:generate
npm run seed
npm run build
npm run start:prod
```

健康检查地址：

```text
https://api.example.com/health
```

生产环境上线后，请立即修改种子账号默认密码。

## 管理后台

进入管理后台目录：

```powershell
cd apps/admin
Copy-Item .env.example .env.local
```

修改 `.env.local`：

```env
NEXT_PUBLIC_API_URL=https://api.example.com
```

构建：

```powershell
npm install
npm run build
npm run start
```

默认本地服务端口由 Next.js 控制，部署时建议由 Nginx 反向代理到后台服务。

## 独立客服端

进入客服端目录：

```powershell
cd apps/support
Copy-Item .env.example .env.local
```

修改 `.env.local`：

```env
NEXT_PUBLIC_API_URL=https://api.example.com
```

构建并启动：

```powershell
npm install
npm run build
npm run start
```

如果团队只使用管理后台里的“在线客服”页面，独立客服端可以不单独部署。

## 客户 App

客户 App 的接口地址通过 `API_BASE_URL` 注入。

Web 构建：

```powershell
cd apps/client
flutter pub get
flutter build web --dart-define=API_BASE_URL=https://api.example.com
```

Android APK：

```powershell
cd apps/client
flutter pub get
flutter build apk --release --dart-define=API_BASE_URL=https://api.example.com
```

Android AAB，适合提交应用商店：

```powershell
flutter build appbundle --release --dart-define=API_BASE_URL=https://api.example.com
```

正式发布前必须配置 Android release 签名，详见 `docs/客户APP发布配置.md`。

## Nginx 反向代理

API 需要支持普通 HTTP 请求和 WebSocket 行情连接。反向代理时要保留升级头：

```nginx
location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

管理后台和客服端可以按普通 Next.js 服务反向代理。

## 上线检查

上线前执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify-all.ps1
```

并手动确认：

- API `/health` 正常
- 管理员、财务、客服、业务员都能登录
- 客户注册只显示手机号、密码、邀请码
- KYC 只允许 Aadhaar 或 PAN
- Deposit 进入在线客服，不在 App 内提交入金申请
- Withdraw 可以提交，并生成订单号
- 财务可以审核提现
- 业务员只能看到自己的客户
- 客服标签只在客服后端展示

## 生产安全项

- 修改所有默认后台账号密码
- 使用强 `JWT_SECRET`
- 数据库只允许服务器内网访问
- 配置 HTTPS
- 设置数据库自动备份
- 不要提交 `.env`、`.env.local`、`key.properties`、keystore 文件
- 定期导出资金流水、提现记录和审核日志
