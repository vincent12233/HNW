# HNW Trading 项目运行和迁移说明

## 更新代码后必须做

1. 打开 Docker。
2. 进入项目根目录：
   `cd C:\Users\Vincent\hnw_trading_app`
3. 同步数据库结构：
   `cd apps\api`
   `npx prisma migrate deploy`
   `npx prisma generate`

最近新增的数据库内容包括：
- 贷款申请与还款登记
- 客服内部备注、优先级、会话状态
- 股票公司 Logo、分类、显示排序

## 本地启动

API：
`cd C:\Users\Vincent\hnw_trading_app\apps\api`
`npm run start:dev`

管理后台：
`cd C:\Users\Vincent\hnw_trading_app\apps\admin`
`npm run dev`

客服独立后台：
`cd C:\Users\Vincent\hnw_trading_app\apps\support`
`npm run dev`

客户 App Web：
`cd C:\Users\Vincent\hnw_trading_app\apps\client`
`flutter run -d web-server --web-hostname 0.0.0.0 --web-port 8081 --dart-define=API_BASE_URL=http://localhost:3000`

浏览器打开客户 App 时使用：
`http://localhost:8081`

不要打开：
`http://0.0.0.0:8081`

## 常见端口

- API：`http://localhost:3000`
- 管理后台：通常 `http://localhost:3001` 或 Next.js 显示的端口
- 客服后台：通常 `http://localhost:3001` 或 Next.js 显示的端口
- 客户 App：`http://localhost:8081`

如果提示 `EADDRINUSE: address already in use :::3000`，说明 API 已经在运行，不需要重复启动。

## 关键业务规则

- 客户注册只需要印度手机号、密码、邀请码。
- 客户入金不在 App 内提交申请，点击 Deposit 后联系在线客服，财务后台上分。
- 客户提现在 App 内提交，后台生成订单号，财务审核。
- KYC 上传 Aadhaar 或 PAN，业务员后台审核。
- 业务员只能看到自己的客户。
- 管理员、财务、客服可按各自权限看到全部客户。
- 贷款只能由管理员/财务审核，通过后自动到账客户账户。
- 贷款还款只做后台登记，不从客户交易账户扣款。
- IPO 客户只提交申请，业务员分配数量；系统自动扣款，不足生成欠款，补足后自动转入持仓。
