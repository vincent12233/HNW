# HNW 当前项目审计（2026-09-24）

## 结论

本地 `main` 与 `origin/main` 在审计开始时一致且工作区干净。项目已有完整的 Flutter 客户端、Next.js 多角色后台、NestJS API、设计系统，以及覆盖一级、二级和三级页面的加载、空态、错误、重试、窄屏和大字号测试。

本轮不改交易方式、订单语义、资金记账、KYC 规则、行情接入、域名或部署结构。界面不需要再次整体重做；继续大范围换皮会制造重复组件和回归风险。

## 印度市场产品对照

对照 Zerodha Kite、Groww、Angel One 与 Dhan 的公开产品资料后，HNW 现有信息架构已覆盖当前业务允许的核心体验：五项底部导航、统一搜索、自选列表、指数与股票详情、专业图表、买卖票据、订单和持仓状态、投资组合、IPO、通知、KYC、两步验证、生物识别快捷登录、客服、法律文档和双语界面。

主流产品还有多自选分组、期权链、篮子单、GTT、价格提醒、从图表下单、热力图、企业行动、共同基金和 SIP 等能力。这些不是纯外观升级，会改变产品范围或交易方式，所以本轮没有照搬。

参考：

- Zerodha Kite：通用搜索、轻量界面、图表、市场深度、GTT、篮子单与风险提示。
- Groww：集中式持仓和收益视图，股票详情中的概览、新闻、基本面、相似股票与买卖操作。
- Angel One：数字 KYC、两步验证、搜索、图表、订单、市场观察和风险信息。
- Dhan：自选分组、图表交易、组合洞察和高级订单；这些超出本轮“只升级外观”的边界。

## 本轮实施

1. 发布版 API 地址只允许公网 HTTPS 或同源相对路径；拒绝 HTTP、回环、私网、链路本地、文档地址、用户信息 URL 和本地主机名。
2. Android 主清单禁用明文流量与应用备份；debug/profile 清单保留本地 HTTP 联调能力。
3. 新增发布地址与 Android 清单安全回归测试。
4. Flutter 锁文件升级 12 个兼容的传递依赖补丁/小版本；直接依赖保持不变。
5. 删除无路由、无实现、无调用方的空 `StocksModule` 脚手架；真实股票功能仍由现有市场模块承担。
