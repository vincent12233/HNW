# HNW 运营流程说明

## 后台账号

初始化后会创建以下后台账号：

| 角色 | 员工编号 | 密码 |
| --- | --- | --- |
| 超级管理员 | ADMIN001 | `ADMIN_INITIAL_PASSWORD` 环境变量 |
| 管理员 | MANAGER001 | `MANAGER_INITIAL_PASSWORD` 环境变量 |
| 财务 | FINANCE001 | `FINANCE_INITIAL_PASSWORD` 环境变量 |
| 业务员 | BUSINESS001 | `BUSINESS_INITIAL_PASSWORD` 环境变量 |

后台员工只使用员工编号和密码登录，不使用邮箱。

生产环境上线后请立即修改默认密码。

## 客户注册

客户 App 使用英文界面。

客户注册只需要：

- 印度手机号
- 登录密码
- 邀请码

不需要邮箱，不需要短信验证码。

手机号支持：

- 10 位印度手机号，例如 `9876543210`
- 带国家码，例如 `919876543210`

客户注册成功后，系统会自动生成内部客户编号。客户 App 不展示该编号，后台可用于搜索和管理。

## 邀请码

每个邀请码只能注册一个客户。

业务员可以在 `我的邀请码` 页面生成自己的邀请码。管理员也可以在 `业务员管理` 中为指定业务员生成邀请码。

如果测试脚本提示没有可用邀请码，需要先生成新的邀请码。

## KYC 审核

客户注册后进入 KYC 上传页面。

客户只能上传：

- Aadhaar
- PAN

支持文件格式：

- PDF
- JPG / JPEG
- PNG
- WEBP

系统会根据客户选择和文件名做基础自动识别。客户所属业务员在 `KYC 审核` 页面查看文件、预览证件、填写备注，并通过或拒绝。

KYC 通过后，客户账号才进入可登录状态。

## 客户入金

客户 App 不提交入金申请。

客户在 APP 首页点击 **Add Funds** 后进入 App 内的 **Deposit** 页（充值说明、入金历史、条款），再通过页内「Contact customer support」进入在线客服。侧边客服按钮是独立入口，与充值页不同。

客服向客户提供充值方式，确认信息后由财务后台手动上分。客户端不展示平台收款账户，也不在 App 内提交入金申请。超管「客户端运营配置」可维护充值页文案与预填消息（**充值页**模块），不维护存款/收款账户。

财务操作路径：

1. 登录财务后台。
2. 进入 `财务上分`。
3. 搜索客户手机号、客户编号或交易账号。
4. 输入上分金额、付款流水号和备注。
5. 确认上分。

业务员可以查看自己客户已完成的入金记录，但不能审核或上分。

## 客户端运营配置

超级管理员可在后台菜单 **客户端运营配置** 维护 APP 可运营文案（不含存款/收款账户）：

| 模块 | 可维护内容 | 语言 |
| --- | --- | --- |
| 首页 | 首页/行情横幅；公司区标题与视频/官网按钮；Add Funds / Withdraw 按钮；总资产/可用资金标签；指数区与「查看全部」；市场新闻；个人中心分区标题、概览指标与帮助/Insights/About/条款/退出等入口文案 | en / hi |
| 充值页 | 页面标题、主标题、充值说明、联系客服按钮、客服预填消息、接口拒绝提示、入金历史区标题/空状态、条款区标题与正文 | en / hi |
| 客服 | 侧边悬浮按钮文案、面板标题、欢迎语、服务时间滚动公告、快捷主题标签、输入提示、SaleSmartly URL、预填消息；标签与快捷回复 | 客户端文案 en / hi；标签/快捷回复中文 |
| 交易说明 | 机构/OTC/IPO 空状态与确认文案；组合页标题/总价值/摘要/配置标题与空状态；持仓空状态；交易引导 | en / hi |
| About | 主体名称、地址、申诉联系方式等 | en |
| 法律文本 | Privacy / Terms（JSON 分段） | en |
| Wealth Insights | 介绍与文章列表 | en / hi |

公司实体图文（名称、简介、视频/官网链接）在 **平台公司信息** 维护，与文案 CMS 分开。

部署后需执行 Prisma migrate（含 `app_ops_content` 与 `app_ops_legal_insights`）。缺失的默认条目会在 API 首次读取时由 `ensureDefaults` 自动补齐。

## 客户提现

客户在 App 内提交提现申请。

提现申请会生成订单号，客户提现记录和后台提现记录都可以看到该订单号，方便查找。

财务操作路径：

1. 登录财务后台。
2. 进入 `提现审核`。
3. 使用订单号、手机号、客户编号或交易账号搜索。
4. 核对收款信息。
5. 通过或拒绝提现。

业务员可以查看自己客户的提现记录，但不能审核。

## 在线客服

客服在 SaleSmartly 中查看客户会话。

客服功能包括：

- 客服内部标签
- 自定义备注标签
- 快捷回复
- 翻译辅助

标签只显示在 SaleSmartly 工作台，客户 App 看不到。

客户入金入口会联系在线客服，由客服沟通充值方式，财务确认到账后上分。

## 交易记录

客户 App 下单必须通过后端订单接口，不再本地伪造成交。

后台权限：

- 管理员可以查看所有客户订单和成交。
- 财务可以查看所有客户订单和成交。
- 业务员只能查看自己名下客户的订单和成交。

## 股票维护

股票维护在管理员后台完成。

路径：

1. 登录管理员后台。
2. 进入 `股票管理`。
3. 添加股票或修改行情价格。
4. 确认股票处于启用状态。

启用后的股票会进入客户 App 行情和交易列表。

常用字段：

- 交易所：`NSE` 或 `BSE`
- 类型：股票、ETF、指数
- 代码：例如 `INFY`
- 名称：例如 `Infosys Limited`
- ISIN：可选
- 最小跳动：例如 `0.05`
- 最新价：必须大于 0
- 成交量：可选，默认 0

如果某只股票暂时不允许交易，可以在 `股票管理` 中停用。

以下模块只显示在管理员后台，不显示在客户 App：

- 大宗交易
