# 行情陈旧处置手册

## 影响与触发

交易时段行情时间戳超限、序列缺口、WebSocket 重连风暴或数据源连续失败时触发。陈旧行情必须明确显示，不得伪装为实时行情。

## 检查顺序

1. 核对印度交易时段、节假日与服务器时间同步。
2. 检查供应商连接、最近序列号、接收时间、快照刷新及 TimescaleDB 缓冲区。
3. 比较独立授权行情源，确认是单标的、单实例还是全局问题。
4. 检查 API/WebSocket 容量和最近发布，不记录用户标识。

## 安全缓解与回滚

- 维持陈旧/延迟标识并触发快照恢复；必要时暂停依赖实时价格的新交易入口。
- 可切换已批准的备用供应商或回滚应用镜像；恢复前验证序列连续性和价格时间戳。
- 恢复后执行开盘突发与重连测试，观察至少一个规定窗口。

## 升级与禁止事项

通知交易平台和值班负责人。若价格影响交易决定或持续跨越阈值，升级为重大事件。

禁止伪造时间戳、重复广播旧价格、静默隐藏陈旧状态或在未经批准时接入公共/未授权数据源。
