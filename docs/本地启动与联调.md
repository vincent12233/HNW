# 本地启动与联调

## 1. 启动数据库

先打开 Docker Desktop，然后复制 `.env.docker.example` 为 `.env.docker`，设置五个后台账号密码，再在项目根目录执行：

```powershell
docker compose up -d --build
```

本地数据库配置来自 `compose.yaml`：

- 数据库：`hnw_trading`
- 用户：`hnw_user`
- 密码：`hnw_dev_password`
- 端口：`5432`

API 的本地 `.env` 默认指向该数据库。

## 2. 初始化数据库结构

在 `apps/api` 目录执行：

```powershell
npx prisma migrate deploy
npx prisma generate
```

## 3. 初始化后台账号和邀请码

在 `apps/api` 目录执行：

```powershell
npm run seed
```

初始化后可使用：

| 后台 | 员工编号 | 密码 |
| --- | --- | --- |
| 超级管理员 | ADMIN001 | `ADMIN_INITIAL_PASSWORD` 环境变量 |
| 管理员 | MANAGER001 | `MANAGER_INITIAL_PASSWORD` 环境变量 |
| 财务 | FINANCE001 | `FINANCE_INITIAL_PASSWORD` 环境变量 |
| 业务员 | BUSINESS001 | `BUSINESS_INITIAL_PASSWORD` 环境变量 |

初始测试邀请码：

- HNWBIZ000001
- HNWBIZ000002
- HNWBIZ000003

每个邀请码只能使用一次。用完后可用业务员账号登录后台，在 `我的邀请码` 页面继续生成。

## 4. 启动 API

在 `apps/api` 目录执行：

```powershell
npm run start:dev
```

默认地址：

```text
http://localhost:3000
```

健康检查：

```text
http://localhost:3000/health
```

## 5. 启动管理后台

在 `apps/admin` 目录执行：

```powershell
Copy-Item .env.example .env.local
npm run dev
```

默认访问：

```text
http://localhost:3002/login
```

后台统一使用中文，员工只使用员工编号和密码登录。

## 6. 启动客户 App

在 `apps/client` 目录执行：

```powershell
flutter pub get
flutter run --dart-define=API_BASE_URL=http://localhost:3000
```

客户 App 统一使用英文。

## 7. 完整业务联调顺序

1. 业务员登录后台，确认可生成邀请码。
2. 客户 App 使用印度手机号、密码、邀请码注册。
3. 客户上传 Aadhaar 或 PAN 做 KYC。
4. 业务员后台审核该客户 KYC。
5. 客户登录 App，点击 Deposit 联系 SaleSmartly 在线客服。
6. 客服在 SaleSmartly 中处理客户会话和标签。
7. 财务后台搜索客户，手动上分。
8. 客户 App 提交 Withdraw。
9. 财务后台根据订单号审核提现。
10. 业务员后台查看自己客户的入金、提现、订单和成交记录。

## 9. 一键冒烟脚本

API、后台账号、数据库都准备好后，在项目根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\VERIFY-test.ps1
```

脚本会自动验证：

- 业务员登录
- 客户手机号注册
- PAN KYC 上传
- 业务员审核 KYC
- 客户登录
- 客户联系客服入金
- 客服添加内部标签
- 财务上分
- 客户真实下单
- 管理员可见订单
- 财务可见成交
- 业务员可见自己客户订单
- 客户提交提现
- 业务员查看提现订单号
- 财务审核提现

脚本每执行一次会消耗一个未使用邀请码。如果没有可用邀请码，脚本会自动用 `BUSINESS001` 生成新的邀请码后继续执行。

## 10. 添加股票

新增或维护股票时，使用管理员后台 `股票管理` 入口。

可执行操作：

- 添加股票
- 搜索股票
- 修改行情价格
- 启用或停用股票
- 初始化示例行情

客户 App 会从 API 的行情快照同步启用中的股票。后台新增股票后，重新进入 App 行情页即可看到。

## 11. 构建检查

推荐在项目根目录执行统一检查：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify-all.ps1
```

脚本会自动执行客户 App 的 `flutter pub get`，再运行 `flutter analyze`。

如果只想检查构建，不跑业务冒烟：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify-all.ps1 -SkipVerification
```

也可以分别执行：

API：

```powershell
cd apps/api
npm run build
```

管理后台：

```powershell
cd apps/admin
npm run build
```

客户 App：

```powershell
cd apps/client
flutter analyze
flutter build web --dart-define=API_BASE_URL=http://localhost:3000
```
