# 移动端双端同步说明

本项目的客户 App 使用 Flutter 开发，Android 和 iOS 共用 `apps/client/lib` 里的业务代码、页面、接口请求、状态处理和 UI 组件。

## 已统一

- App 显示名称：Android 和 iOS 均为 `India Trading App`
- App 内部名称：`AppConfig.appName` 为 `India Trading App`
- API 接入方式：统一使用 `--dart-define=API_BASE_URL=...`
- Android 正式包网络权限：已在主 Manifest 中启用
- Flutter 依赖和版本号：由同一个 `pubspec.yaml` 管理

## 后续修改原则

1. 客户端功能、按钮、页面、接口逻辑优先修改 `apps/client/lib`，这样 Android 和 iOS 会自动同步。
2. 只有启动图、App 图标、包名、签名、证书、权限这类平台外壳，才分别修改 `android` 和 `ios` 目录。
3. 每次移动端修改后，至少运行一次：

```powershell
cd apps/client
flutter analyze
```

4. 测试 Android：

```powershell
flutter run -d android --dart-define=API_BASE_URL=http://你的电脑IP:3000
```

5. 测试 iOS：

```powershell
flutter run -d ios --dart-define=API_BASE_URL=http://你的电脑IP:3000
```

如果是真机测试，不要使用 `localhost`，需要使用运行后端那台电脑的局域网 IP。
