# 交付验收清单

## 构建检查

推荐直接运行统一检查：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify-all.ps1
```

脚本会自动执行客户 App 的 `flutter pub get`，再运行 `flutter analyze`。

如果只想跑构建和 Flutter 分析，不跑业务冒烟：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify-all.ps1 -SkipVerification
```

也可以分别执行：

```powershell
cd apps/api
npm run build

cd ../admin
npm run build

cd ../support
npm run build
```

客户 App：

```powershell
cd apps/client
flutter analyze
flutter build web --dart-define=API_BASE_URL=http://localhost:3000
```

Android 包需要本机先配置 `JAVA_HOME` 和 release keystore。

## 核心业务冒烟

项目根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\VERIFY-test.ps1
```

如果没有可用邀请码，脚本会自动用 `BUSINESS001` 生成新的邀请码后继续执行。

脚本会验证：

- 印度手机号 + 密码 + 邀请码注册
- KYC 上传 PAN/Aadhaar
- 业务员审核 KYC
- 客户联系在线客服咨询入金
- 客服标签
- 财务手动上分
- 客户提交提现申请
- 提现订单号生成
- 业务员可见自己客户提现记录
- 财务审核提现
- 客户真实下单
- 管理员可见订单
- 财务可见成交
- 业务员可见自己客户订单

## 交易权限验收

客户买入股票后确认：

- 客户订单状态为 `FILLED`
- 管理员可在订单/成交查询中看到
- 财务可在订单/成交查询中看到
- 业务员只能在自己的客户订单/成交记录中看到
- 客服不能访问业务员交易接口

## 生产上线前

- 修改 API `JWT_SECRET`
- 设置 API `CORS_ORIGINS`
- 设置后台 `NEXT_PUBLIC_API_URL`
- 设置客户 App `API_BASE_URL`
- 配置数据库备份
- 修改默认后台员工密码
- 配置 Android `key.properties` 和 release keystore
